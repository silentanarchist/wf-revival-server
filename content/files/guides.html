Install guides

How to play Warhammer 40,000: Warpforge on the Warpforge Revival server. Unofficial fan project, not affiliated with Everguild or Games Workshop. You need your own copy of the game. Stuck? Ask on our Discord server.

Which guide?
  • Playing on a Windows PC: PC (Windows).
  • Playing on an Android phone: the patcher app is the easiest; with a PC is the older way and still works.
  • Playing the Android version on a PC through an emulator: MuMu Player (uses the Patcher app too).
  • Designing your own cards: the Card Creator guide.
The same account works everywhere and keeps your decks and progress.

PC (Windows)

Play Warhammer 40,000: Warpforge against the Revival server now that the game's own servers are closed. Unofficial fan project, not affiliated with Everguild or Games Workshop. You need your own copy of the game.

You need

  • Warpforge installed through Steam (game version 1.35.0)
  • MelonLoader 0.7.3 - installer and help at melonwiki.xyz
  • The mod: the WarpforgeRevival-...-w.zip file from the latest release

1. Install MelonLoader

  1. Run the MelonLoader installer, pick Warpforge and choose version 0.7.3.
  2. Start the game once. A console window does some work, then the game opens.
  3. Close the game.

2. Install the mod

  1. In Steam, right-click the game > Manage > Browse local files.
  2. Open the Mods folder (create it if it is not there).
  3. Copy the whole WarpforgeRevival folder from the zip into Mods.
  4. Start the game.

You should end up with these two files. Keep manifest.json next to the DLL, or the mod is not loaded.

Mods\WarpforgeRevival\WarpforgeRevival.dll
Mods\WarpforgeRevival\manifest.json

3. Sign in or make an account

If the server asks for an account, a sign-in window appears while the game loads.

New player? Make your account right there. There is no separate form.

  1. In Username, type the username you want (5 to 30 letters, digits, . ' - or _, no spaces).
  2. In Password, type the password you want (at least 6 characters, no spaces). Do not reuse one from another site.
  3. Press Create account.

Already have an account? Type its username and password and press Sign in.

  • The game remembers the sign-in, so it asks only once per computer or phone.
  • The same account works on PC and Android and keeps the same decks and progress.
  • Sign out in Settings > Account signs out this computer only.
  • Make a recovery code on the website's Profile page while you still know your password, and keep the file. Forgot your password? on the website's sign-in page uses it.

Updates

The mod updates itself. When the server has a newer version, the sign-in window says so while the game loads, downloads it, and the game closes and starts again with it.

If something goes wrong

  • The game looks unmodded (no connection, original menus): check both files are in Mods\WarpforgeRevival\ and that MelonLoader is installed.
  • An older copy of the mod cannot connect: delete UserData\WarpforgeRevival.cfg in the game folder and start the game again.
  • Reporting a problem: send the file MelonLoader\Latest.log from the game folder. It says what happened.

Good to know

  • The mod's version is shown next to the game's in Settings > General. PC builds end in -w, Android builds in -a.
  • Keep the game window open while you wait for a match. Minimising is fine.
  • The connection to the server is encrypted (https) when the server offers it, and so are matches against other players.
  • Your original game files are safe. The mod never deletes the game's cached files and stops the game deleting them. It also keeps a second copy in UserData\WarpforgeRevival\original-cache.

Android phone: the Warpforge Patcher app

The Warpforge Patcher app puts the mod loader and the mod into your own copy of the game, on the phone itself. No PC patching, no cable, no adb.

Status: works in MuMu Player and on a Pixel 6 Pro. If it fails on your phone, press Share logs in the app and send the file to us on Discord (see "If something goes wrong" below).

You need

  • An Android phone with a 64-bit ARM processor (every current phone), Android 8 or newer
  • The game, version 1.35.0, installed on the phone, or your own backup of it (one .apks or .xapk file of about 780 MB)
  • About 2 GB free on the phone while patching (given back afterwards)
  • The app: WarpforgePatcher-....apk (about 14 MB) from the Warpforge Patcher release on the Android mod's releases page

1. Install the app

  1. On the phone, open the releases page and download WarpforgePatcher-....apk.
  2. Tap the downloaded file. Android asks whether your browser (or file manager) may install apps: allow it, go back and tap Install.
  3. Open Warpforge Patcher.

2. Give the app its two permissions

The app shows a button for each one it is still missing:

  • Allow access to the loader's folder (All files access): the loader and the mod live in MelonLoader/com.Everguild.WarhammerWarpforge on your phone's storage.
  • Allow this app to install the game.

3. Patch

  1. Leave Fix black menu after loading as the app set it. It is ticked on Pixels (6 and later) and on Samsungs with an Exynos chip and Mali graphics, where the opening video can leave the menu black. It then shows a still picture instead of the video.
  2. Press Patch and install. Patching from a backup file of the game instead? See Patching from a backup file below.
  3. If the game has to be removed first, the app asks before it starts: press Continue. The game's downloaded files go with it; the server hands them out again.
  4. Stay in the app while it works. The big data file takes a few minutes.
  5. Android asks you to confirm removing the old game, then installing the new one. Confirm both.

The two main buttons

  • Patch and install (Patch again and install once the game is patched): puts the mod loader into the game, installs the patched game and puts the current mod in place. Use it the first time and whenever a new loader comes out. Patched by this app before, it installs over the game and keeps everything.
  • Update the mod only: downloads the current mod from the server and puts it in place without touching the game. Use it after a connection error at the title screen, or to get a new mod straight away.

Patching from a backup file

Use Patch from a backup file (.apks / .xapk) when the game is not installed on this phone, or to patch from your own backup of it. The game does not need to be installed for this.

  1. Put the backup on the phone, for example in Download. It is one file of about 780 MB ending in .apks or .xapk, game version 1.35.0. From a PC, copy it over by USB; in MuMu, drag it onto the window.
  2. Check the free space. While it works the app needs about twice the backup's size plus 400 MB (about 2 GB). It tells you if there is not enough.
  3. In Warpforge Patcher, leave Fix black menu after loading as the app set it and press Patch from a backup file (.apks / .xapk). The button works once both permissions are allowed.
  4. Pick the backup in Android's file picker. The app unpacks it and checks that it holds the game's main file, its arm64 code file and the data pack, and that it is version 1.35.0.
  5. From here it is the same as Patch and install: if a copy of the game that this app did not patch is installed, the app asks before removing it (press Continue). Stay in the app while it works, then confirm Android's prompts.

If the app says the backup is missing the arm64 code file or the data pack, the backup was made without all its parts: make it again with every part included. "This is game version …" means the backup is not version 1.35.0.

4. Play

  1. Start Warpforge from your home screen. If it asks for "All files access", allow it.
  2. The first start sits on a black screen for up to a minute while the loader sets itself up. Later starts are quicker.
  3. If the server asks for an account, a sign-in window appears while the game loads. New player: type the username (5 to 30 characters) and password (at least 6) you want, then press Create account. Existing account: type its name and password and press Sign in. The same account works on PC and phone.

Updates

  • The mod updates itself. The app's Update the mod only button does the same by hand.
  • A new loader means opening the app and pressing Patch again and install. It installs over your patched game without removing it, so nothing is lost.

Keep the app's signing key

The first patch makes a signing key inside the app. Every later patch has to use the same key, or the game has to be removed again. Press Save a copy of the signing key and keep the file somewhere private. If you ever reinstall the app, Load a saved signing key puts it back. Never share that file.

If something goes wrong

Send the logs: they show whoever is helping you what happened.

  1. Right after the problem, open Warpforge Patcher. Do it before you start the game again: every start of the game replaces the loader's log.
  2. Press Share logs. Android's share menu opens with one zip file.
  3. Pick Discord (or email) and send it in a direct message to whoever is helping you, with a line on what happened and your phone model.

The zip holds the app's log, the loader's log and the mod's settings, never your game login. It can still contain your player id and the server address, so do not post it in a public channel.

  • Not enough free space: the app says how much it needs. Free some space and press the button again.
  • "The data pack is missing": start the original game once so Android finishes downloading it, then try again.
  • "This is game version ...": the mod only works with game version 1.35.0.
  • The app closes while patching: open it and press the button again. If it keeps happening, send the logs.
  • Game patched on a PC before: the app's key is different from the PC's, so the game has to be removed once. After that the app patches over it.
  • Connection error at the title screen: press Update the mod only, or check the server is up.
  • Black screen after the opening video: tick Fix black menu after loading and press Update the mod only.
  • Black screen during a match: turn on the game's Settings > Graphics > Extended compatibility, then restart.

Prefer the PC route? The Android phone: with a PC guide still works the same way.

Android phone: patched with a PC

Status: works on a Pixel 8 Pro and a Pixel 6 Pro (Android 17), and in MuMu Player on a PC. Other phones are untested. If it fails on yours, the logs are what is needed to find out why (see the end of this guide).

You need

  • A Windows PC and a USB cable
  • An Android phone with a 64-bit ARM processor (every current phone)
  • Your own copy of the Android game, version 1.35.0: a backup of the app made from your own phone, one file of about 780 MB ending in .apks or .xapk. Other versions will not work.
  • About 3 GB free on the PC and 2 GB free on the phone
  • Google's SDK Platform-Tools for Windows

Everything comes from the Android mod repository. Its front page has these same steps in full detail.

1. Get the patcher

On the repository page press the green Code button, then Download ZIP. Unzip it somewhere with a short path, for example C:\warpforge-android. Everything you run is in the patcher folder.

2. Put your game files in

Put your backup file (.apks or .xapk) straight into the patcher folder. Or put its three .apk files into patcher\game-files.

3. Patch

Double-click 1 - patch.bat. The big data file takes a few minutes. When it finishes, the patched folder holds three files that belong together:

base.apk   config.arm64_v8a.apk   UnityDataAssetPack.apk

If it stops with an error, the details are in patcher\patch-log.txt.

Keep your signing key. The first patch makes patcher\tool\signing-key.pem. Every later patch has to be signed with that same key, or Android refuses it and the game has to be removed again. Keep the file, keep it private, and never share a patcher folder that has it inside.

4. Switch on USB debugging

  1. On the phone: Settings > About phone, tap Build number seven times.
  2. Settings > System > Developer options, switch on USB debugging.
  3. Connect the phone to the PC by cable and accept "Allow USB debugging?" on the phone.
  4. Unzip Google's platform-tools so that this file exists: patcher\tool\platform-tools\adb.exe

5. Install on the phone

Double-click 2 - install on phone.bat.

  • If the game on the phone was patched before with the same signing key, the new copy installs over it and nothing is lost.
  • Otherwise the install is refused and the script asks whether to remove the copy on the phone first. It only goes ahead if you type YES. The game's downloaded files go with it; the server hands them out again.

No cable? Copy the three files from patched to the phone and install them together with a split-APK installer app such as SAI. Tapping base.apk on its own does not work.

6. First start

  1. Start the game once. If it asks for "All files access", allow it.
  2. The first start sits on a black screen for up to a minute while it copies the loader's files.
  3. It then stops at the title screen with a connection error. That is expected without the mod.
  4. Close the game (swipe it away from the recent apps).

7. Put the mod on the phone

  1. Download the mod from the latest release and unzip it.
  2. Copy WarpforgeRevival.Android.dll into patcher\mods.
  3. Double-click 3 - put mod on phone.bat.

Without a PC: copy the file on the phone itself into MelonLoader/com.Everguild.WarhammerWarpforge/Mods/.

8. Play

Start the game. It reaches the menu in about half a minute.

If the server asks for an account, a sign-in window appears while the game loads. New player: type the username (5 to 30 characters) and password (at least 6) you want, then press Create account. Existing account: type its name and password and press Sign in. The same account works on PC and phone.

Prefer not to type on the phone? Download a game login file from the website's Profile page and run 4 - put game login on phone.bat. Treat that file like a password.

Updates

  • The mod updates itself. When the server has a newer build, the sign-in window says so, downloads it and closes the game. Open the game again to use it.
  • The loader does not. A new loader means running 1 - patch.bat and 2 - install on phone.bat again. With the same signing key it installs over the old copy and keeps everything.

Removing it

Double-click 5 - uninstall from phone.bat with the phone connected. Your account, decks and progress are on the server and stay there.

If something goes wrong

Connect the phone and double-click 0 - get phone logs.bat. Press 1 if the game is closed and you are about to start it, or 2 if it is open and something just went wrong. Send the new folder under patcher\phone-logs. The logs can contain your player id and the server address, so do not post them publicly.

  • The install is refused: the copy on the phone was signed with a different key. See step 5.
  • Connection error at the title screen: the mod is not on the phone (step 7), or the server cannot be reached.
  • Black screen after the opening video (seen on a Pixel 6 Pro): the mod brings the picture back within a second or two. To stop it happening, run 6 - fix loading video.bat (option 1, needs ffmpeg - the script says where to get it), then 7 - loading video setting.bat (option 1, Still). The loading screen then shows a still picture instead of the video.
  • Opening video blocky or stuttering: 6 - fix loading video.bat (option 1) fixes that too.
  • Black screen during a match: turn on the game's Settings > Graphics > Extended compatibility, then restart.
  • The game closes by itself while loading: open it again. If it keeps happening, collect logs with 1.
  • Stuck or closes within seconds of starting: swipe the app away and start again. If it keeps happening, collect logs with 2 before closing it.

Android on PC (MuMu Player)

Runs the Android version of the game, with the mod, inside the MuMu Player emulator on a Windows PC. No scripts, no adb: the Warpforge Patcher app does the patching inside MuMu. MuMu is the only emulator tested so far.

You need

  • MuMu Player on your PC
  • Your own copy of the Android game, version 1.35.0, as one .xapk (or .apks) file of about 780 MB. Other versions will not work.
  • The app: WarpforgePatcher-....apk from the Warpforge Patcher release on the Android mod's releases page

1. Put both files into MuMu

  1. Start MuMu and wait for the Android home screen. Run one MuMu device only.
  2. Drag the game's .xapk file onto the MuMu window. MuMu installs the game. Wait until its icon appears.
  3. Drag WarpforgePatcher-....apk onto the MuMu window. MuMu installs the app.

2. Patch

  1. Open Warpforge Patcher in MuMu.
  2. Allow the two permissions it asks for: Allow access to the loader's folder (All files access) and Allow this app to install the game.
  3. Press Patch and install. The app asks before it removes the original game: press Continue. Stay in the app while it works; the big data file takes a few minutes.
  4. Confirm MuMu's two prompts: removing the original game, then installing the patched one.

The app also puts the current mod in place. Nothing else to copy.

3. Play

  1. Start the game in MuMu and allow "All files access" when it asks. The first start sits on a black screen for a minute or so while the loader sets itself up.
  2. If the server asks for an account, a sign-in window appears while the game loads: sign in, or type a new name (5 to 30 characters) and password (at least 6) and press Create account. The same account works on PC and phone.
  3. Check the mod is running: its version is shown next to the game's in Settings > General.

The two main buttons

  • Patch and install (Patch again and install once the game is patched): puts the mod loader into the game, installs the patched game and puts the current mod in place. Use it the first time and whenever a new loader comes out.
  • Update the mod only: puts the current mod in place without touching the game. The mod also updates itself when the game starts.

If something goes wrong

  • MuMu did not install the .xapk when you dropped it: open Warpforge Patcher, press Patch from a backup file and pick the .xapk (MuMu puts dropped files in its shared folder or in Download).
  • Connection error at the title screen: press Update the mod only in the app, or check the server is up.
  • Black screen during a match: turn on the game's Settings > Graphics > Extended compatibility and restart it.
  • Anything else: right after the problem, before you start the game again, open Warpforge Patcher and press Share logs. Send the zip in a direct message to whoever is helping you, with a line on what happened. It never includes your game login, but it can contain your player id, so do not post it in a public channel.

Prefer the old way with adb and the PC scripts? The Android phone: with a PC guide still works for MuMu: connect with adb connect 127.0.0.1:16384 and run the scripts as for a phone.

Card Creator

The Card Creator is where you design a troop, stratagem or warlord for Warpforge Revival. Reviewers check every card before it goes anywhere near a match.

Before you start

A card moves through these stages:

  1. Draft: saved with Save draft. Only you can see it.
  2. Waiting for review: sent with Submit for review.
  3. Approved or Rejected: a reviewer decides and can leave a note, which you see on the card. A rejected card can be fixed and sent again.
  4. Testing, then release: approved cards go to testers first (the Custom Test mode), then to everyone in the custom mode once they pass. This part is still being set up.

The Card Creator has six tabs along the top:

TabWhat it is for
Create a cardThe editor. Everything below.
My cardsYour drafts and submitted cards, with their status. Open one to edit it; drafts and rejected cards can be discarded.
ExamplesPick a keyword to see official cards that use it, exactly as the game stores them.
KeywordsThe keyword cheat sheet (what each keyword does, by faction) and the stratagem type cheat sheet.
ArtworkSizes, templates, the pop-out mask and a downloadable art kit.
RulesWhat a card and its artwork must follow. You confirm them before submitting.

Limits: a name holds up to 40 characters, the card text and the flavour text up to 300 each, and the notes for the reviewer up to 1,000.

The Create a card page

The page has two columns. On the left you build the card in five sections, top to bottom: Basics, Action, Keywords, Abilities and Card text. On the right the Preview redraws the card as you type and holds the save buttons. Work down the left column in order; the card text comes last because it describes what you built above it.

Action

Something the player chooses to do during their turn. A card has at most one. Press + Add an action to open its box:

  • Kind of action: Duty, Ferocity, Pray, Agenda, Oath, or a plain action. The card gets that keyword by itself.
  • Energy cost to use (for Oath: Oath number, the energy the Oath costs).
  • Limits or conditions: free text for limits the fields cannot express, for example "once per turn".
  • Effects: what the action does. + Add effect adds more, resolved in order.
  • What the player picks for the action: appears once an effect aims at "the chosen target".

The box also explains what the game adds for you. For example, a Ferocity troop returns to the deck by itself, so you add only the effect.

Keywords

Press + Add keyword and pick one. The number after each name is how many official cards use it. Each keyword row has:

  • Value, for keywords that carry a number (Blast, and so on).
  • works by itself, for keywords that need nothing else (Flying, Stealth, Vanguard, Ephemeral).
  • A box under it, for keywords that say when something happens (Rally, Talent, Strike, Artifice): fill in what happens there, the same way as an ability.
  • Official examples, which opens the Examples tab on that keyword.
  • A warning when official cards only have that keyword on another kind of card.

Abilities

For abilities that belong to no keyword. Press + Add ability. An ability is one trigger followed by one or more effects, resolved in order.

  • When: the trigger. Choices used by many official cards are the safest; ones marked 0 exist in the game but no official card uses them.
  • Triggered by which units or cards: for triggers about another unit ("whenever a friendly troop dies"). Tick Friendly, Enemy, Troops, Warlords, and narrow it by keyword or unit type.
  • More options: where the card must be for it to work, whose turn, timing, whether the play icon shows, a cost in points (faith, spirit stones), "only if" a count or a random roll, "pick one effect at random", and "repeat once for each …".

Each effect has:

  • Effect: what happens, for example deal damage, heal, buff, summon, draw.
  • Amount, Up to (a random range), How many and Which card, depending on the effect.
  • Affects: who it hits. Pick a group, then At most and If picking some, the Friendly, Enemy, Troops, Warlords and Stratagems tick boxes, and filters by keyword, unit type or condition. More filters has the rarer ones.
  • Describe what this should do: for an effect the fields cannot express. The reviewer reads it.
  • More options: where the amount comes from, damage type, repeat, chance, which player, "only while this card is in play", and "once for each …".

When any effect aims at "the chosen target", What the player picks when playing the card appears under the abilities. Leave it as it is to take the first chosen-target effect's filter, say exactly what may be picked, or let the trigger decide.

Card text

  • Card text: the rules text printed on the card, up to 300 characters. How to make keywords bold is under Keywords in card descriptions below.
  • Suggest text from the abilities: writes a first draft of the text from what you built. Check it and add the bold marks yourself.
  • Flavour text (optional): a line of story or a quote, like the lore on official cards, up to 300 characters. Not rules.
  • Notes for the reviewer: never shown on the card. Balance thoughts, art ideas, anything the fields could not express.

Preview and saving

  • The card, drawn with the game's own frame and art. Long text gets a smaller font. The in-game layout can differ a little.
  • This card follows all of the card creator rules: must be ticked to submit, not to save a draft.
  • Submit for review, Save draft and New card (clears the editor).
  • Faction warning: a yellow box when the card uses a keyword, trigger or effect from another faction. The game allows it, but such mechanics often do nothing outside their own faction.
  • Review note: the reviewer's note, when there is one.
  • Build notes: after a save, what the server could and could not write into the game's card data.
  • Design data and Game data: the card as the creator stores it and as the game will store it. For checking, not for editing.

Making a card, step by step

An example troop: Pack Hunter, a Space Wolves troop that deals 2 damage to an enemy troop when played. The same order works for any card.

  1. Find a model card. In Examples, pick the keyword your card is built around (here Rally) and look at how official cards do it. The simplest are listed first.
  2. Fill in Basics. Name Pack Hunter, Kind Troop, Faction Space Wolves, Rarity Common, Cost 2, Melee 2, Ranged 0, Health 2, Armour 0, Unit type Infantry.
  3. Pick the art. Type an official card's name under Artwork – borrow from an existing card, or press …or upload your own artwork and place it.
  4. Add the keyword. Under Keywords, press + Add keyword and pick Rally. A box opens under it for what Rally does.
  5. Build the effect in that box: Effect Deal damage, Amount 2; Affects The chosen target, with Enemy and Troops ticked and the rest unticked.
  6. Check what the player picks. What the player picks when playing the card appears because the effect aims at the chosen target. Leave it on the default.
  7. Write the card text. Press Suggest text from the abilities, then edit it and mark the keyword: **Rally**: Deal 2 damage to an enemy troop.
  8. Check the preview. The name, stats, art and text should look right, with Rally in bold. Fix any yellow faction warning, or explain it in the notes.
  9. Save a draft to keep it private, then read the Build notes. They say whether everything was written into the game data.
  10. Submit. Tick This card follows all of the card creator rules and press Submit for review. Follow it under My cards.

Keywords in card descriptions

To show a keyword in bold, put two asterisks on each side of it in the card text: **Rally**. This is the same mark the game's own card texts use, on 907 of the 1,217 official cards that have rules text. The preview turns it bold as you type.

A keyword shows up in two places, and each comes from a different part of the creator:

  • Bold in the card text comes only from the ** marks you type in Card text.
  • The keyword itself, the one the game acts on and lists beside the unit with what it does, comes from the Keywords or Action section. Writing **Flying** in the text does not give the card Flying; adding Flying under Keywords does not write it in the text. Do both.

Common slips

  • One asterisk (*Rally*) is not the mark. It stays on the card as typed.
  • A missing pair (**Rally: Deal 2) leaves the asterisks visible. Check the preview: every keyword should be bold and no asterisk should show.
  • Spaces inside the marks (** Rally **): keep the marks tight against the word.
  • Bold sentences: mark keywords only, as the official cards do.
  • Suggest text from the abilities writes plain text. Add the marks after using it.
  • The marks count toward the 300 characters, four per keyword.

Card art

Every card's art is one 1024 × 1024 picture. Bring any size: the creator crops and scales it when you upload. The Artwork tab has the full guide and a download kit (art-kit.zip: both templates, a blank mask and an example sheet).

CardWhat showsAim for
Troops and warlordsA portrait strip 670 pixels wide in the middle of the square, full height. The name and text sit over the lower part, darkened.At least 670 × 1024, portrait (about 2 : 3). Landscape pictures are cropped hard at the sides.
StratagemsNearly the whole square. The top right corner sits under the faction badge and cost, the bottom strip under the text box.At least 1024 × 1024.
  • Formats: PNG, JPG or WebP, up to 20 MB. Saved as a 1024 × 1024 PNG.
  • Pop-out mask (troops and warlords, optional): a second picture, white where the art should be drawn over the frame (a weapon, a banner), black everywhere else. Paint it over the picture as the creator saved it, so the two line up.
  • Uploads are stored straight away, drafts included. Admins see every upload and remove any that break the rules: only art you made or may use, nothing sexual, hateful or offensive, and no real people.

Saving, submitting and what happens next

  • Save draft keeps the card private. You can come back to it from My cards at any time.
  • Submit for review needs the rules box ticked. The card then shows as Waiting for review under My cards.
  • A reviewer approves or rejects it and can leave a note, shown on the card when you open it. Reviewers cannot approve their own cards; another reviewer or an admin has to.
  • Rejected? Open it from My cards, fix what the note says and submit again. Drafts and rejected cards can also be discarded there.
  • Approved cards go to testers first, in the Custom Test mode, and to everyone later once they pass testing. This step is still being set up, so approved cards may not be in matches yet.
