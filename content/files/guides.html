Install guides

How to play Warhammer 40,000: Warpforge on the WF Revival server. Unofficial fan project, not affiliated with Everguild or Games Workshop. You need your own copy of the game. Stuck? Ask on our Discord server.

Which guide?
  • Playing on a Windows PC: PC (Windows).
  • Playing on an Android phone, tablet or other Android device: the patcher app is the easiest; with a PC is the older way and still works.
  • Playing the Android version on a PC through an emulator: MuMu Player (uses the Patcher app too).
  • Designing your own cards: the Card Creator guide.
  • Seeing official card art on this site: export it from your game.
The same account works everywhere and keeps your decks and progress.

PC (Windows)

Play Warhammer 40,000: Warpforge against the Revival server now that the game's own servers are closed. Unofficial fan project, not affiliated with Everguild or Games Workshop. You need your own copy of the game.

You need

  • Warpforge installed through Steam (game version 1.35.0)
  • MelonLoader 0.7.3 - installer and help at melonwiki.xyz
  • The mod: the WFRevival-...-w.zip file from the latest release

Want to check the download? It's the same file as on GitHub, and the SHA-256 is the one GitHub lists for it on the release page. If you want, check your copy with any SHA-256 tool. If it doesn't match, don't use it: download it again and tell us on Discord.

1. Install MelonLoader

  1. Run the MelonLoader installer, pick Warpforge and choose version 0.7.3.
  2. Start the game once. A console window does some work, then the game opens.
  3. Close the game.

2. Install the mod

  1. In Steam, right-click the game > Manage > Browse local files.
  2. Open the Mods folder (create it if it is not there).
  3. Copy the whole WFRevival folder from the zip into Mods.
  4. Start the game.

You should end up with these two files. Keep manifest.json next to the DLL, or the mod is not loaded.

Mods\WFRevival\WFRevival.dll
Mods\WFRevival\manifest.json

3. Sign in or make an account

If the server asks for an account, a sign-in window appears while the game loads.

New player? Make your account right there in the game. You do not need the website first.

  1. Press Create account. A form opens.
  2. In Username, type the username you want (5 to 30 letters, digits, . ' - or _, no spaces).
  3. In Password, type the password you want (at least 6 characters, no spaces), and the same again in Again. Do not reuse one from another site.
  4. Tick I am 16 or older and agree to the Terms and Privacy notice. Read shows them.
  5. Press Create account. Back returns to the sign-in window.

Already have an account? Type its username and password and press Sign in.

  • The game remembers the sign-in, so it asks only once per computer or device.
  • The same account works on PC and Android and keeps the same decks and progress.
  • Settings > Account in the game shows which account it is signed in with. Open profile on website opens your Profile page; Sign out signs out this computer only.
  • Make a recovery code on the website's Profile page while you still know your password, and keep the file. Forgot your password? on the website's sign-in page uses it.

Updates

The mod updates itself. When the server has a newer version, the sign-in window says so while the game loads, downloads it, and the game closes and starts again with it.

If something goes wrong

  • The game looks unmodded (no connection, original menus): check both files are in Mods\WFRevival\ and that MelonLoader is installed.
  • An older copy of the mod cannot connect: delete UserData\WarpforgeRevival.cfg in the game folder and start the game again.
  • Reporting a problem: send the file MelonLoader\Latest.log from the game folder. It says what happened.

Good to know

  • The mod's version is shown next to the game's in Settings > General. PC builds end in -w, Android builds in -a.
  • Keep the game window open while you wait for a match. Minimising is fine.
  • The connection to the server is encrypted (https) when the server offers it, and so are matches against other players.
  • Your original game files are safe. The mod never deletes the game's cached files and stops the game deleting them. It also keeps a second copy in UserData\WarpforgeRevival\original-cache.

Android device: the WF Revival Patcher app

Uninstalled the game? If you installed Warpforge from the Play Store before, you may be able to reinstall it: see Google's Reinstall & re-enable apps. Use the same Google account you had then. The mod needs game version 1.35.0; the Patcher app checks this for you.

The WF Revival Patcher app puts the mod loader and the mod into your own copy of the game, on the device itself. No PC patching, no cable, no adb.

Status: works in MuMu Player and on a Pixel 6 Pro. If it fails on your device, press Share logs in the app and send the file to us on Discord (see "If something goes wrong" below).

You need

  • An Android phone, tablet or other Android device with a 64-bit ARM processor (every current phone and most tablets), Android 8 or newer
  • The game, version 1.35.0, installed on your device, or your own backup of it (one .apks or .xapk file of about 780 MB)
  • About 2 GB free on your device while patching (given back afterwards)
  • The app: WFRevivalPatcher-....apk (about 14 MB) from the newest WF Revival Patcher release on the mod's releases page

Want to check the download? It's the same file as on GitHub, and the SHA-256 is the one GitHub lists for it on the release page. If you want, check your copy with any SHA-256 tool. If it doesn't match, don't use it: download it again and tell us on Discord.

1. Install the app

  1. On your device, open the releases page and download WFRevivalPatcher-....apk.
  2. Tap the downloaded file. Android asks whether your browser (or file manager) may install apps: allow it, go back and tap Install.
  3. Open WF Revival Patcher.

2. Give the app its two permissions

The app shows a button for each one it is still missing:

  • Allow access to the loader's folder (All files access): the loader and the mod live in MelonLoader/com.Everguild.WarhammerWarpforge on your device's storage.
  • Allow this app to install the game.

3. Patch

  1. Leave Fix black menu after loading as the app set it. It is ticked on Pixels (6 and later) and on Samsungs with an Exynos chip and Mali graphics, where the opening video can leave the menu black. It then shows a still picture instead of the video.
  2. Press Patch and install. Patching from a backup file of the game instead? See Patching from a backup file below.
  3. If the game has to be removed first, the app asks before it starts: press Continue. The game's downloaded files go with it; the server hands them out again.
  4. Stay in the app while it works. The big data file takes a few minutes.
  5. Android asks you to confirm removing the old game, then installing the new one. Confirm both.

The two main buttons

  • Patch and install (Patch again and install once the game is patched): puts the mod loader into the game, installs the patched game and puts the current mod in place. Use it the first time and whenever a new loader comes out. Patched by this app before, it installs over the game and keeps everything.
  • Update the mod only: downloads the current mod from the server and puts it in place without touching the game. Use it after a connection error at the title screen, or to get a new mod straight away.

Patching from a backup file

Use Patch from a backup file (.apks / .xapk) when the game is not installed on this device, or to patch from your own backup of it. The game does not need to be installed for this.

  1. Put the backup on your device, for example in Download. It is one file of about 780 MB ending in .apks or .xapk, game version 1.35.0. From a PC, copy it over by USB; in MuMu, drag it onto the window.
  2. Check the free space. While it works the app needs about twice the backup's size plus 400 MB (about 2 GB). It tells you if there is not enough.
  3. In WF Revival Patcher, leave Fix black menu after loading as the app set it and press Patch from a backup file (.apks / .xapk). The button works once both permissions are allowed.
  4. Pick the backup in Android's file picker. The app unpacks it and checks that it holds the game's main file, its arm64 code file and the data pack, and that it is version 1.35.0.
  5. From here it is the same as Patch and install: if a copy of the game that this app did not patch is installed, the app asks before removing it (press Continue). Stay in the app while it works, then confirm Android's prompts.

If the app says the backup is missing the arm64 code file or the data pack, the backup was made without all its parts: make it again with every part included. "This is game version …" means the backup is not version 1.35.0.

4. Play

  1. Start Warpforge from your home screen. If it asks for "All files access", allow it.
  2. The first start sits on a black screen for up to a minute while the loader sets itself up. Later starts are quicker.
  3. If the server asks for an account, a sign-in window appears while the game loads. New player: press Create account, type the username (5 to 30 characters) and password (at least 6) you want, type the password again in Again, tick the box that you are 16 or older and agree to the Terms, then press Create account. Existing account: type its name and password and press Sign in. The same account works on PC and Android.

Updates

  • The mod updates itself. The app's Update the mod only button does the same by hand.
  • A new loader means opening the app and pressing Patch again and install. It installs over your patched game without removing it, so nothing is lost.
  • The app updates itself. When a new WF Revival Patcher is out, it offers the update when you open it. Check for updates at the top right looks at any time. Mod 0.14.0 and newer need WF Revival Patcher 0.3.0 or newer: the app offers it as a required update. If your app is older than 0.2.2, install the new one by hand once.

The Tools page

Press Tools under the title for the extra tools. Buttons that need the loader's folder stay grey until that permission is allowed.

  • Black screen fix: Apply the black screen fix shows a still picture instead of the loading video, for devices that end up on a black menu after loading. It works on the already patched game; nothing is patched again.
  • Server: shows which server the mod connects to. For now there is only the community server, so you can leave this alone. (Change the server picks another one, or switches back to the community server; close the game fully first.)
  • Card art: Save card art export to Downloads copies the card art you exported in the game to your Download folder, where it is easy to pick on the website. See the card art guide.
  • Signing key: save or load the app's signing key (below).

Keep the app's signing key

The first patch makes a signing key inside the app. Every later patch has to use the same key, or the game has to be removed again. On the Tools page, press Save a copy of the signing key and keep the file somewhere private. If you ever reinstall the app, Load a saved signing key puts it back. Never share that file.

If something goes wrong

Send the logs: they show whoever is helping you what happened.

  1. Right after the problem, open WF Revival Patcher. Do it before you start the game again: every start of the game replaces the loader's log.
  2. Press Share logs. Android's share menu opens with one zip file.
  3. Pick Discord (or email) and send it in a direct message to whoever is helping you, with a line on what happened and your device model.

The zip holds the app's log, the loader's log and the mod's settings, never your game login. It can still contain your player id and the server address, so do not post it in a public channel.

  • Not enough free space: the app says how much it needs. Free some space and press the button again.
  • "The data pack is missing": start the original game once so Android finishes downloading it, then try again.
  • "This is game version ...": the mod only works with game version 1.35.0.
  • The app closes while patching: open it and press the button again. If it keeps happening, send the logs.
  • Game patched on a PC before: the app's key is different from the PC's, so the game has to be removed once. After that the app patches over it.
  • Connection error at the title screen: press Update the mod only, or check the server is up.
  • Black screen after the opening video: on the Tools page, press Apply the black screen fix.
  • Black screen during a match: turn on the game's Settings > Graphics > Extended compatibility, then restart.

Prefer the PC route? The Android device: with a PC guide still works the same way.

Android device: patched with a PC

Uninstalled the game? If you installed Warpforge from the Play Store before, you may be able to reinstall it: see Google's Reinstall & re-enable apps. Use the same Google account you had then. The mod needs game version 1.35.0: check the version before patching.

Status: works on a Pixel 8 Pro and a Pixel 6 Pro (Android 17), and in MuMu Player on a PC. Other devices are untested. If it fails on yours, the logs are what is needed to find out why (see the end of this guide).

You need

  • A Windows PC and a USB cable
  • An Android phone, tablet or other Android device with a 64-bit ARM processor (every current phone and most tablets)
  • Your own copy of the Android game, version 1.35.0: a backup of the app made from your own device, one file of about 780 MB ending in .apks or .xapk. Other versions will not work.
  • About 3 GB free on the PC and 2 GB free on the device
  • Google's SDK Platform-Tools for Windows

Everything comes from the WF Revival mod repository, which holds the PC and Android parts. Its Android page has these same steps in full detail.

1. Get the patcher

On the repository page press the green Code button, then Download ZIP. Unzip it somewhere with a short path, for example C:\warpforge-android. Everything you run is in the patcher folder.

2. Put your game files in

Put your backup file (.apks or .xapk) straight into the patcher folder. Or put its three .apk files into patcher\game-files.

3. Patch

Double-click 1 - patch.bat. The big data file takes a few minutes. When it finishes, the patched folder holds three files that belong together:

base.apk   config.arm64_v8a.apk   UnityDataAssetPack.apk

If it stops with an error, the details are in patcher\patch-log.txt.

Keep your signing key. The first patch makes patcher\tool\signing-key.pem. Every later patch has to be signed with that same key, or Android refuses it and the game has to be removed again. Keep the file, keep it private, and never share a patcher folder that has it inside.

4. Switch on USB debugging

  1. On your device: Settings > About phone (About tablet on a tablet), tap Build number seven times.
  2. Settings > System > Developer options, switch on USB debugging.
  3. Connect your device to the PC by cable and accept "Allow USB debugging?" on the device.
  4. Unzip Google's platform-tools so that this file exists: patcher\tool\platform-tools\adb.exe

5. Install on your device

Double-click 2 - install on phone.bat.

  • If the game on your device was patched before with the same signing key, the new copy installs over it and nothing is lost.
  • Otherwise the install is refused and the script asks whether to remove the copy on your device first. It only goes ahead if you type YES. The game's downloaded files go with it; the server hands them out again.

No cable? Copy the three files from patched to your device and install them together with a split-APK installer app such as SAI. Tapping base.apk on its own does not work.

6. First start

  1. Start the game once. If it asks for "All files access", allow it.
  2. The first start sits on a black screen for up to a minute while it copies the loader's files.
  3. It then stops at the title screen with a connection error. That is expected without the mod.
  4. Close the game (swipe it away from the recent apps).

7. Put the mod on your device

Want to check the download? It's the same file as on GitHub, and the SHA-256 is the one GitHub lists for it on the release page. If you want, check your copy with any SHA-256 tool. If it doesn't match, don't use it: download it again and tell us on Discord.

  1. Download WFRevival.Android-...-a.zip from the latest release and unzip it. (The same release also has the PC file, ending in -w.zip.)
  2. Copy WFRevival.Android.dll into patcher\mods.
  3. Double-click 3 - put mod on phone.bat.

Without a PC: copy the file on the device itself into MelonLoader/com.Everguild.WarhammerWarpforge/Mods/.

8. Play

Start the game. It reaches the menu in about half a minute.

If the server asks for an account, a sign-in window appears while the game loads. New player: press Create account, type the username (5 to 30 characters) and password (at least 6) you want, type the password again in Again, tick the box that you are 16 or older and agree to the Terms, then press Create account. Existing account: type its name and password and press Sign in. The same account works on PC and Android.

Prefer not to type on your device? Download a game login file from the website's Profile page and run 4 - put game login on phone.bat. Treat that file like a password.

Updates

  • The mod updates itself. When the server has a newer build, the sign-in window says so, downloads it and closes the game. Open the game again to use it.
  • The loader does not. A new loader means running 1 - patch.bat and 2 - install on phone.bat again. With the same signing key it installs over the old copy and keeps everything.

Removing it

Double-click 5 - uninstall from phone.bat with your device connected. Your account, decks and progress are on the server and stay there.

If something goes wrong

Connect your device and double-click 0 - get phone logs.bat. Press 1 if the game is closed and you are about to start it, or 2 if it is open and something just went wrong. Send the new folder under patcher\phone-logs. The logs can contain your player id and the server address, so do not post them publicly.

  • The install is refused: the copy on your device was signed with a different key. See step 5.
  • Connection error at the title screen: the mod is not on your device (step 7), or the server cannot be reached.
  • Black screen after the opening video (seen on a Pixel 6 Pro): the mod brings the picture back within a second or two. To stop it happening, run 6 - fix loading video.bat (option 1, needs ffmpeg - the script says where to get it), then 7 - loading video setting.bat (option 1, Still). The loading screen then shows a still picture instead of the video.
  • Opening video blocky or stuttering: 6 - fix loading video.bat (option 1) fixes that too.
  • Black screen during a match: turn on the game's Settings > Graphics > Extended compatibility, then restart.
  • The game closes by itself while loading: open it again. If it keeps happening, collect logs with 1.
  • Stuck or closes within seconds of starting: swipe the app away and start again. If it keeps happening, collect logs with 2 before closing it.

Android on PC (MuMu Player)

Uninstalled the game? If you installed Warpforge from the Play Store before, you can reinstall it with the Google Play Store inside MuMu, signed in to the same Google account. Use Google Play, not the MuMu Store: the MuMu Store may list Warpforge too, but its copy does not come from Google or your account, and it may not be the publisher's original file. See Google's Reinstall & re-enable apps. The mod needs game version 1.35.0; the Patcher app checks this for you.

Runs the Android version of the game, with the mod, inside the MuMu Player emulator on a Windows PC. No scripts, no adb: the WF Revival Patcher app does the patching inside MuMu. MuMu is the only emulator tested so far.

You need

  • MuMu Player on your PC
  • Your own copy of the Android game, version 1.35.0, as one .xapk (or .apks) file of about 780 MB. Other versions will not work.
  • The app: WFRevivalPatcher-....apk from the newest WF Revival Patcher release on the mod's releases page

Want to check the download? It's the same file as on GitHub, and the SHA-256 is the one GitHub lists for it on the release page. If you want, check your copy with any SHA-256 tool. If it doesn't match, don't use it: download it again and tell us on Discord.

1. Put both files into MuMu

  1. Start MuMu and wait for the Android home screen. Run one MuMu device only.
  2. Drag the game's .xapk file onto the MuMu window. MuMu installs the game. Wait until its icon appears.
  3. Drag WFRevivalPatcher-....apk onto the MuMu window. MuMu installs the app.

2. Patch

  1. Open WF Revival Patcher in MuMu.
  2. Allow the two permissions it asks for: Allow access to the loader's folder (All files access) and Allow this app to install the game.
  3. Press Patch and install. The app asks before it removes the original game: press Continue. Stay in the app while it works; the big data file takes a few minutes.
  4. Confirm MuMu's two prompts: removing the original game, then installing the patched one.

The app also puts the current mod in place. Nothing else to copy.

3. Play

  1. Start the game in MuMu and allow "All files access" when it asks. The first start sits on a black screen for a minute or so while the loader sets itself up.
  2. If the server asks for an account, a sign-in window appears while the game loads: sign in, or press Create account, type a new name (5 to 30 characters) and password (at least 6), the password again in Again, tick the 16-or-older box and press Create account. The same account works on PC and Android.
  3. Check the mod is running: its version is shown next to the game's in Settings > General.

The two main buttons

  • Patch and install (Patch again and install once the game is patched): puts the mod loader into the game, installs the patched game and puts the current mod in place. Use it the first time and whenever a new loader comes out.
  • Update the mod only: puts the current mod in place without touching the game. The mod also updates itself when the game starts.

If something goes wrong

  • MuMu did not install the .xapk when you dropped it: open WF Revival Patcher, press Patch from a backup file and pick the .xapk (MuMu puts dropped files in its shared folder or in Download).
  • Connection error at the title screen: press Update the mod only in the app, or check the server is up.
  • Black screen during a match: turn on the game's Settings > Graphics > Extended compatibility and restart it.
  • Anything else: right after the problem, before you start the game again, open WF Revival Patcher and press Share logs. Send the zip in a direct message to whoever is helping you, with a line on what happened. It never includes your game login, but it can contain your player id, so do not post it in a public channel.

Prefer the old way with adb and the PC scripts? The Android device: with a PC guide still works for MuMu: connect with adb connect 127.0.0.1:16384 and run the scripts as for any other Android device.

Card Creator

The Card Creator is where you design your own cards for WF Revival. Reviewers check every card before it goes anywhere near a match.

Before you start

A card moves through these stages:

  1. Draft: saved with Save draft. Only you can see it.
  2. Waiting for review: sent with Submit for review.
  3. Approved or Rejected: a reviewer decides and can leave a note, which you see on the card. A rejected card can be fixed and sent again. An approved card can only be changed by an admin.
  4. Testing, then release: approved cards go to testers first (the Custom Test mode), then to everyone in the custom mode once they pass. This part is still being set up.

The Card Creator has seven tabs along the top:

Tab What it is for
Create a card The editor. Everything below.
My cards Your drafts and submitted cards, with their status. Open one to edit it; drafts and rejected cards can be discarded.
Examples Pick a keyword to see official cards that use it. Load in editor puts a copy in the editor as a new card; nothing is saved until you save.
Card viewer Every official card, with how the game builds it. Its pictures come from your own game (see Card art below).
Keywords The keyword cheat sheet (what each keyword does, by faction) and the stratagem type cheat sheet.
Artwork Sizes, templates, the pop-out mask and a downloadable art kit.
Rules What a card and its artwork must follow. You confirm them before submitting.

Limits: a name holds up to 40 characters, the card text and the flavour text up to 300 each, and the notes for the reviewer up to 1,000.

The Create a card page

The page has two columns. On the left you build the card from top to bottom: Basics, the Show advanced options switch, Keywords and abilities, Card settings (advanced options only) and Card text. On the right the Preview redraws it as you type and holds the save buttons. Work down the left column in order; the card text comes last because it describes what you built above it.

Basics

Field What it does
Name The card's name, up to 40 characters.
Card template What kind of card it is, and what the editor offers for it. A line under the menus describes the template you chose. See the table below.
Faction One of the 13 factions, or Neutral. Sets the card frame.
Rarity Common, Rare, Epic or Legendary. Sets the frame's tier. (Special and None exist for created cards.)
Cost Energy to play it, -1 to 14.
Melee, Ranged, Health, Armour Troops and warlords only.
Unit type Infantry, Vehicle, Monster, Building, Battlesuit, Drone, Beast or Daemon. Other cards can target by it.
Created by another card only Tick it for a troop, warlord or stratagem that another card summons or adds to a hand; it is then kept out of the collection and decks. Shown only for the Troop, Warlord and Stratagem templates; the others set it themselves.
Artwork – borrow from an existing card Type an official card's name to use its art.
…or upload your own artwork Your own picture. Save the card once first. See Card art below.
Artwork credit Appears once you have uploaded a picture: who made it, and an optional link.
Add a pop-out mask (optional) Troops and warlords only. Lets part of the picture break out over the frame.

Card template decides what kind of card it is:

Template What it is What the template sets
Troop A unit deployed to the battlefield. Nothing.
Warlord The warlord a deck is built around. Nothing.
Stratagem A card you put in a deck and play. A locked "When this is played" ability first.
Talent card A card a warlord's Talent adds to the hand. Created by a card, always Ephemeral, locked "When this is played". Give your warlord a Talent ability that adds this card.
Defence card The card a deck uses when going second (picked in the deck editor's own slot). A locked "When this is played".
Offence card A card the player going first can pick at the start of a battle. Created by a card, locked "When this is played". Effects that last all battle (weather, turn start or end, skulls) go on an Enchantment card this one attaches.
Enchantment A hidden card other cards attach with an "Attach an enchantment" buff. Its abilities act for the card it is attached to; its cost, stats and text are not used. Battlefield effects are enchantments. Created by a card. Can use field triggers (turn start or end, skull earned) and unit keywords.
Sabotage card A card another card puts into the enemy's hand, which works while it sits there, like Poisoned Supplies. Created by a card. Every ability listens from the hand.

The template also limits the lists to what the game can do for that kind of card. A played stratagem goes to the graveyard at once, so it cannot use unit keywords like Strike or Slay; its extra abilities happen either straight after it is played or while it is in your hand.

Show advanced options

A switch between Basics and the keywords. Only the tick box itself switches it, and the browser remembers it.

  • Off (the default): the editor shows only what official cards use for your choices.
  • On: it also shows rarely used settings (timing, "works while the card is …"), the Card settings section, and keywords and triggers no official card uses, at the bottom of each list under "Untested – no official card uses it".

Keywords and abilities

One list for everything the card does. + Add a keyword or ability opens a searchable picker. Each entry has a one-line description and how many official cards use it.

Picker tab What it holds Examples
Static Keywords that work by themselves. Some take a number. Flying, Stealth, Vanguard, Armour 1, Blood Thirst
Ability Keywords that say when something happens. Each opens a box under it for what happens. Rally, Strike, Slay, Talent, Codex, Mob
Action Something the player uses during their turn, with its own cost and effects. A card has at most one, and actions only come from this tab. Duty, Pray, Oath, Agenda, Ferocity
Custom (pick a trigger) An ability without a keyword: you pick when it happens. Keyword triggers are never here. When a unit attacks; at the end of a turn; when another unit dies; Faith; Spirit Stone; "then, after this card's effects"

Every entry has Remove; keywords also have Official examples, which opens the Examples tab on that keyword.

Inside an ability or action:

  • What the player picks: only on abilities where the player really chooses a unit (when played, Codex, Faith, Spirit Stone, the follow-up, and actions). Its filter decides what can be clicked: Friendly or Enemy, Troops or Warlords, a keyword, a unit type, "only if …". The pick is made once, when the card is played; later abilities on the card reuse it.
  • Effects ("Effect 1", + Add effect, up to 8): the effect, its numbers, and Who does it affect? (below).
  • More options: folded extras. Most cards never need them.
  • Pray cards: the "praying state" every official Pray card has shows as one line inside the Pray action.

Who does it affect? offers different choices depending on the trigger:

The ability is … Choose
One where the player picks "A unit the player picks" (filter it in the pick box above), or "The picked unit, only if it also matches …" for an extra condition on one effect ("if it is a Vehicle, also stun it").
Set off by an event about a unit (attacks, Strike, stuns, deaths, Swarm) "The unit the event is about (e.g. the unit attacked)", or "That unit, only if it also matches …". Like Venomthrope: destroy any troop attacked.
Any other trigger (Slay, turn start or end …) "Every unit that matches …" or "Random unit(s) that match …", with the filter set there. The player cannot pick here; for a real choice, have the ability add a card (for example an Ephemeral stratagem) whose "When played" has a pick.

On every ability you can also choose "This card", "Your warlord" or "The enemy warlord" (no filters), the unit that set it off, cards in hand, deck or cemetery that match, and units next to this card or to the picked unit.

Card settings (advanced options only)

Rare card-level settings a few official cards use: a "Choose one of these" window when played; the player waiting until it has resolved; whether "a random card" effects can create it; collection and decks; attack damage type; keyword hints on the card; a count of its targets on the card in hand; for warlords, a card in the starting hand and a card given when going second. + Add an alternative action is for cards with an action: it is used instead when the action's condition fails, like Wulfen Pack Leader.

Card text

  • Card text: the rules text printed on the card, up to 300 characters.
  • Suggest text from the abilities: writes a first draft from what you built, with keywords in bold as on official cards, for example **Flying**. **Strike**: Deal 1 damage to the unit it hit. It is a starting point to edit, not a final text.
  • Flavour text (optional): a line of lore, up to 300 characters. Not rules.
  • Notes for the reviewer: never shown on the card, up to 1,000 characters. Anything the editor cannot express, balance thoughts, art ideas.

Preview and saving

  • The card, drawn with the game's own frame. The frames and official art come from your own game's card art export, loaded on your Profile page; without it the preview shows an outline. "Art by …" appears under it when uploaded art has a credit.
  • This card follows all of the card creator rules: must be ticked to submit, not to save a draft.
  • Submit for review, Save draft and New card (clears the editor).
  • Faction warning: a yellow box when the card uses another faction's mechanic. The game allows it, but such mechanics often do nothing outside their own faction.
  • Build notes: after a save, plain-language warnings from the server, for example "no artwork chosen". Read them before submitting.
  • Design data and Game data: the card as the creator stores it and as the game will store it. For checking, not for editing.

Making a card, step by step

Five short walkthroughs. Each ends the same way: Suggest text from the abilities, check the preview, then Save draft and read the Build notes.

A simple troop that damages an enemy when played

  1. Card template Troop; give it a name, faction, cost and stats.
  2. + Add a keyword or ability > Static > Flying.
  3. + Add a keyword or ability > Ability > Rally.
  4. In the Rally box, What the player picks: tick Enemy and Troops.
  5. Effect 1: Deal damage, amount 2. Who does it affect? A unit the player picks.

A stratagem

  1. Card template Stratagem. The locked "When this is played" ability is already there.
  2. Add its effect and set What the player picks.
  3. Optional follow-up: + Add a keyword or ability > Custom > "Then, after this card's effects", for things like "if the target dies, draw a card".

A talent card for a warlord

  1. Make the talent card first: Card template Talent card (Ephemeral is added by itself). Add its effects and save it.
  2. On the warlord: Ability > Talent, effect Add a card to your hand, and pick the talent card you saved.

"Whenever this unit attacks"

  1. + Add a keyword or ability > Custom > "When a unit attacks".
  2. Effect 1: Stun. Who does it affect? The unit the event is about (e.g. the unit attacked).

The game decides the unit here, so there is no pick box.

Learning from an official card

  1. Open the Examples tab and pick a keyword.
  2. Press Load in editor on a card. A copy opens in the editor as a new card; nothing is saved until you save.
  3. Look at how it is built, then change it into your own card.

Keywords in card descriptions

To show a keyword in bold, put two asterisks on each side of it in the card text: **Rally**. This is the same mark the game's own card texts use, on 907 of the 1,217 official cards that have rules text. The preview turns it bold as you type.

A keyword shows up in two places, and each comes from a different part of the creator:

  • Bold in the card text comes only from the ** marks in Card text. Suggest text from the abilities adds them for you; when you write or edit the text yourself, add them by hand.
  • The keyword itself, the one the game acts on and lists beside the unit with what it does, comes from Keywords and abilities. Writing **Flying** in the text does not give the card Flying; adding Flying in the picker does not write it in the text. Do both, or use Suggest text and then edit.

Common slips

  • One asterisk (*Rally*) is not the mark. It stays on the card as typed.
  • A missing pair (**Rally: Deal 2) leaves the asterisks visible. Check the preview: every keyword should be bold and no asterisk should show.
  • Spaces inside the marks (** Rally **): keep the marks tight against the word.
  • Bold sentences: mark keywords only, as the official cards do.
  • Text written before the last change: if you add or remove a keyword after writing the text, update the text too, or press Suggest text again and redo your edits.
  • The marks count toward the 300 characters, four per keyword.

Card art

Every card's art is one 1024 × 1024 picture. The Artwork tab has the full guide and a download kit (art-kit.zip: both templates, a blank mask and an example sheet).

Official art and frames come from your own game. The website does not hand out the game's pictures. Export them with the mod (Settings > Mod > Export card art) and load the file on your Profile page; the Card art guide has the steps. Without it, borrowed art and frames show as outlines.

Uploading your own picture:

  1. Save the card once (a draft is enough).
  2. Press …or upload your own artwork and pick a PNG, JPG or WebP file (up to 20 MB).
  3. In Place the artwork, drag to move, use the mouse wheel or Zoom to scale, or Fit, Fill and Centre. Then Use this artwork. It is saved at 1024 × 1024.
  4. Fill in Artwork credit: Artist (up to 80 characters) and Link (optional), which must start with http:// or https:// (the original post or the artist's page). Press Save credit. It is stored with the picture and shows as "Art by …" under the preview.

Remove uploaded artwork sets the picture aside.

  • Only upload art you made, or art whose artist gave you permission. A credit alone is not permission. For fan art: ask the artist first, keep their "yes", credit them, and take the picture down if they ask.
  • Uploads are stored straight away, drafts included. Admins see every upload and remove any that break the rules: nothing sexual, hateful, harassing or offensive, and no real people. Breaking the rules can cost you access to the creator.

Saving, submitting and what happens next

  • Save draft keeps the card private. You can come back to it from My cards at any time.
  • Submit for review needs the rules box ticked. The card then shows as Waiting for review under My cards.
  • A reviewer approves or rejects it and can leave a note, shown on the card when you open it. Reviewers cannot approve their own cards; another reviewer or an admin has to.
  • Rejected? Open it from My cards, fix what the note says and submit again. Drafts and rejected cards can also be discarded there.
  • Approved cards can only be changed by an admin. They go to testers first, in the Custom Test mode, and to everyone later once they pass testing. This step is still being set up, so approved cards may not be in matches yet.

Card art from your game

The website no longer hands out the game's card pictures. To see official card art and frames on the site, you export them from your own copy of the game with the mod, then load that file into your browser. Nothing is uploaded: the pictures stay on your device.

Once loaded, the website uses them in:

  • the Card viewer, to draw every official card with its art, pop-out and frame;
  • Create a card, for the faction frame in the preview and for Artwork – borrow from an existing card.

Without the file those pages still work, but official cards show as outlines without pictures. Your own uploaded artwork is not affected.

The same steps work on Windows and Android. Only where the file is saved, and how you get it to the browser, differ.

1. Export the art in the game (Windows and Android)

  1. Update the mod. In the game, open Settings > Mod and press Check for updates. The export button arrived in mod 0.13.15, and the Compress Card Art box in 0.13.27; older versions do not have them.
  2. Open the Collection once, so the game has loaded the cards. If you skip this, the export says "No cards loaded yet: open the Collection once, then try again."
  3. Go back to Settings > Mod. Under Export card art, leave Compress Card Art ticked, or untick it for full-size pictures (see below).
  4. Press Export card art.
  5. Wait. The button counts up ("Exporting card art… 250 / 1335"), then shows "Exporting card frames…". Compressed, it takes a minute or two. You can keep the game open; do not close it until it finishes.
  6. Done when the button says Card art saved with the file's size. On Windows the folder with the file opens by itself.

If it says Card art export failed, try again once. If it fails again, send the game's log (Windows: MelonLoader\Latest.log in the game folder; Android: the Patcher app's Share logs).

The file is always called card-art-export.zip. Exporting again replaces it.

You do not need to unzip it.

3. Load it on the website

  1. Sign in to the Revival website and open your Profile (click your name at the top right).
  2. Find "Card art and text from your game" and press Pick card-art-export.zip.
  3. Choose the file:
    • Windows: go to the game folder, then UserData\WarpforgeRevival, and pick card-art-export.zip.
    • Android device: in the device's browser, the button opens Android's file picker. If the picker shows only recent files, open its menu and choose your device's storage.     • The other device: to use an Android device's export in a PC browser (or the other way round), copy the zip across first, for example by USB cable.
  4. Wait a few seconds. The box then says Loaded: with the number of pictures and frames, the export date and the game version.
  5. Check it worked: open Card Creator > Card viewer. Official cards now show their art and frames, and the line above them says the art comes from your game's export.

The browser keeps the file, so later visits use it by itself. Each browser and each device needs it picked once. Remove from this browser forgets it.

Rules and common problems

  • Keep the export to yourself. It is the game's own art from your copy of the game. Do not share the zip, and do not upload its pictures as your card's artwork: to use an official picture on a card, pick it under Artwork – borrow from an existing card instead. Uploaded artwork must be your own.
  • Export again after a game or mod update that changes cards, then pick the new file on your Profile.
